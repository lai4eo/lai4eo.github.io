# {% include icon.html icon="fa-solid fa-users" %}Team

The Core Team maintain the harmonised database and are signatories to the
[LAI4EO Collaboration Agreement](https://drive.google.com/file/d/1-e-KTbwJrrcchIktZkSxD6IvpJf48EwF/view), which sets out how the database is
governed and released. Every group that contributes measurements is
acknowledged as a member of the Consortium.
